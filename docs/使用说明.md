# FBA 智能工具 — 用户使用说明（三大功能）

> 适用版本：**V3.2 便携版**（`dist/FBA_Smart_Tool_V3.2_便携版.zip`，tag v3.2，2026-10-17）。时间均为美东时间。
> 说明只讲“怎么用”。规则依据见 `docs/用户决策记录.md`（D-01 申报价、D-02 产品库以领星为准、D-06 地址核实等）。

## 〇、启动与数据存放

1. 双击根目录 `一键启动.bat`（开发版），或打包版里的 `启动FBA工具.bat`。浏览器会自动打开，一般是 `http://127.0.0.1:8002`（端口被占用时自动顺延）。
2. 所有业务数据都在 **`app_data/`**：产品库数据库 `fba_master.db`、配置 `config/`、模板 `templates/`、日志 `logs/`。备份就复制整个 `app_data/`。
   - 出厂默认配置：打包版在 **`FBA_Smart_Tool\_internal\config\`**（`*.default.json`），开发版在 `backend/config/`。不要直接改这里，改了会在下次更新时被覆盖。
   - `user_settings.json` 或 `formulas.json` 被改坏（不是合法 JSON）时，界面顶部会出现黄色提示并写日志，程序暂时用出厂值；改好（或删掉）后刷新页面提示消失，不用重启。
   - 测试或远程启动时可设环境变量 `FBA_APP_DATA_DIR`（换数据目录）和 `FBA_NO_BROWSER=1`（不自动打开浏览器）。
3. 程序只在本机监听；不要把 `app_data/config/lingxing.json` 发给别人（里面是加密后的领星密钥，换电脑要重新填）。

## 一、产品库（领星同步 + 手填 + 仓库地址库）

**在哪里**：左侧栏「主数据」页。

### 1. 第一次：填领星密钥
- 「领星 ERP 一键同步」卡片 → 系统设置里填 **领星 MCP Key**，保存。密钥用 Windows DPAPI 加密保存，文件里没有明文。

### 2. 手动拉取（随时可用）
- 点「一键同步」→ 等进度条走完 → 下方出现**预览**：新增 / 有变更 / SKU 对不上 / 无变化。
- 默认已勾好建议写入的字段，核对后点「确认写入」。没确认之前产品库不会变。

### 3. 定时自动同步（默认关闭）
- 同一卡片里的「定时自动同步」：勾「启用」，填间隔（15–10080 分钟）。改完立即生效，面板上“下次”时间会跟着变。
- 程序开着才会定时跑；重启后按“上次成功时间 + 间隔”接着算，已过期的会在启动约 1 分钟后补跑一次。
- 写入规则：
  - 产品库以领星为准（D-02），定时同步会自动写入默认勾选的字段。
  - **你手改过的字段会锁定，不会被领星覆盖**；例外是**申报价**：按 D-01，领星售价优先，你手填的申报价保留，但导出时会提示“手填申报价未采用”。
  - SKU 对不上、英文品名/品牌（报关敏感）这类不会自动写，记为“待人工确认”，在预览里手动确认。
- 失败会自动重试（默认 3 次，间隔逐次加长）；**密钥无效/失效**这类重试也没用的错误只试一次。
- 「同步记录」表：每次同步一行（方式、第几次尝试、状态、差异条数），点开看每条差异；「同步日志」可直接查看。
- 「立即同步 / 重试」：手动立刻跑一次（同步进行中时会提示稍候）。

### 4. 手填 / 批量编辑
- 产品表里直接改单元格，或「导出 Excel → 改完 → 导入预览 → 确认」。
- 箱规可用「箱规导入模板」批量导入；同一文件导两次第二次显示 0 差异。
- 钓具等新品类：补产品字段和 HS 申报要素配置即可；缺报关配置的 SKU 会标“缺报关配置”，可筛选，导出时会被拦住。

### 5. 仓库地址库
- 「导入仓库」上传琪珞发票模板（读其中「！」表）。导入预览里会列出按公开资料纠正过的地址（例如 VGT2 已纠正为 6401 Howdy Wells Avenue, Las Vegas, NV 89115，出处见 `backend/config/fba_warehouse_corrections.json`）。

## 二、发票

**在哪里**：工作流 **Step 4.5 发票**。

### 1. 按货代模板导出（SEND / 九方）——推荐
页面顶部「按货代模板导出发票」卡片：
1. 选货代：SEND 或 九方。
2. 上传亚马逊**货件 CSV**（Seller Central 下载的那份）。
3. 填 Reference ID（亚马逊追踪号）；九方再填订单号。九方如有《单箱数据》可一起上传，用实测重量和尺寸。
   - 仓库：默认按货件 CSV 自动识别（同一城市有多个仓库时用 CSV 里的仓库代码，比如拉斯维加斯 → VGT2）。识别不了时会提示“请在面板上选择仓库”，并在「仓库代码」下拉框列出候选，选好再点预览。也可以直接手填仓库代码。
4. 点「预览」：看箱号区间、每箱件数、单箱重、总件数、总价，以及黄色**提示**（例如“货件待分配，九方箱唛为空”、“手填申报价未采用”、“申报价比历史低”）。
5. 点「导出 xlsx」下载。
- 被**拦截**（红字逐条列出）时不会生成文件，常见原因：产品库缺品名/材质/HS 等字段；钓具 SKU 缺报关配置；九方缺仓库地址；九方单箱数据的外箱号和货件 CSV 对不上。按提示补齐后再导。
- **外箱号对不上时**：面板会出现黄色「确认外箱号更正」框，给每个多出的箱号选它其实是货件里的第几箱，点「确认更正并重新预览」。确认后预览上方会写明按哪些更正导出。
- 规则：数量和金额是数字格式；币种固定 USD；申报价按 D-01；采购价原样带出；同 SKU、同件数、同重量尺寸的连续箱合并成区间，混装箱单独列。

### 2. 旧流程：Step 4 校验后智能生成
- 完成 Step 4（CSV + 箱唛 PDF 校验）后，在 Step 4.5 选货件 →「智能生成发票」→ 在线编辑 → 导出。

### 3. 货代发票模板识别（核对已有发票）
- 后端接口 `/api/invoice-templates/detect`、`/parse` 能识别 8 套历史货代模板（T1–T8）并与货件 CSV 交叉核对，修正建议需要确认后才生效。**目前还没有前端页面**，由测试/开发使用。

## 三、报关资料

**在哪里**：工作流 **Step 5 报关**（Step 4 校验通过后可用）。

1. 选出口方（公司资料在「出口方」设置里维护）和订单号。
2. 选来源：按货件（Step 4 的数据）或按发票草稿。多票合并时每票先算好再合并。
3. 预览 7 张表：报关单、填制规范、申报要素、发票、箱单、合同、委托书。可在页面上改品名、HS、申报要素、件数、净毛重、备注。
4. 导出：默认 **.xlsx**，也可选 **.xls**（两种格式字段一致）。
- 固定规则：出口日期、申报日期、运费（报关单 K12）留空；其它日期按导出当天，可改；口岸默认宁波北仑；委托书有效期为当年 12 月 31 日。
- 申报要素按 HS / 品类从配置取；钓具缺要素会被拦住，不会套用宠物类模板。
- 文件名：一票单独报关、多票合并报关自动命名，可手改。

## 常见问题

| 现象 | 处理 |
|---|---|
| 同步提示“MCP Key无效或已失效” | 去领星 MCP 服务管理页重新生成 Key，在系统设置里重填 |
| 定时同步一直显示“未启用” | 在面板勾「启用」；程序需保持打开 |
| 导出被拦截 | 按红字逐条补产品库/配置，再导 |
| 九方箱唛为空 | 货件还是“待分配”，等亚马逊分配货件号后重新下载 CSV 再导 |
| 想恢复出厂配置 | 删掉 `app_data/config/` 里对应文件，重启后会从出厂默认重新复制（打包版 `FBA_Smart_Tool\_internal\config\*.default.json`，开发版 `backend/config/*.default.json`） |


## V3.2 新增（S9，2026-10-17）

- **领星同步**：适配领星 MCP 新接口，只调用只读工具，每次调用前先核对工具类型。
- **申报价提示**：领星常规价只在采集后 90 天内有效。没有可靠的历史正常价时，预览里显示琥珀色提示「无促销前历史价，申报价可能偏低，请人工确认」，可以在预览里人工确认正常价（只提示，不自动改申报价）。
- **价格解析**：欧式写法（如 12,5）、超大数、科学计数法等直接报错并给出行号；价格上限在「设置 → 参数」里改，默认 100000 美元。
- **SKU 大小写**：按原写法保存；产品库里只差大小写的多条记录报冲突、不合并。导入商品表 / 箱规表时遇到这种冲突，预览里列出行号，确认时整个文件不写入。
- **安装包不带真实数据**：出厂的 SKU / FNSKU 映射和出口商档案都是空的，模板只带格式；**第一次导出报关资料前，先在「设置」里添加出口商档案**。产品信息表格式见 `templates/产品信息表_示例.csv`（只有 DEMO 值，不会导入产品库）。老用户升级时，自己已有的配置、模板和产品库不变。

## V3.1 新增（S8，2026-10-16）

- **尾数分配**：Step 2 分配尾数时数量最多填到剩余尾数；超了后端也会拒绝（400）。箱单数量超过计划数时，内部表和亚马逊表都不让导出。
- **分仓（Step 3.5）**：仓库代码以货件 CSV 为准，文件名只在 CSV 没写时兜底。两者不一致、或都没有时，生成预览后上方出现黄色提示（提示随预览返回，导出这一步不再重复提示）。没有可导出的数据时直接提示，不再生成空表。
- **货代发票（Step 4.5）**：
  - 新增货代：琪珞 T6（下单表，仓库要在琪珞地址表里）、琪珞 T5（发票，需要配送地址；混装尺寸会提示）、德速 T3。
  - “识别货代发票模板”面板：上传货代发来的 Excel，自动识别 T1–T8；识别不准可手选模板；可连同货件 CSV 一起解析，确认后再采用建议值。T5/T7 长得一样时，有数据判 T5、空表判 T7。
  - 最终仓库和 CSV 仓库代码不一致时（比如在面板上手选了别的仓库），导出结果会给提示。
- **促销申报（D-12）**：领星实时售价比正常价低 5% 以上时，按正常价报关并提示。正常价先用领星常规价，没有就用近 90 天最近一次非促销价；划线价不用。5% 和 90 天是可以改的参数（`product_fields.py`）。首次同步就在促销、又没有常规价时无法判断，按实时价报。
- **货代发票重量口径（V3.1 更新）**：德速、琪珞 T6 的重量列有的票填单箱重、有的填单件重。Step 4.5 面板可选“单箱重 / 单件重”；选“自动”并上传货代给的这票发票时，程序把原件重量按两种口径和货件 CSV 核对，只有一种对得上才采用；都没有时重量列留空并提示。
- **HS 编码**：产品库里填 HS 编码必须是 8 或 10 位数字（可带点/空格，保存时去掉；全角数字自动转半角）。钓具参考编码（中国税则 + 美国 HTS 已核对）：钓鱼竿 9507100090、钓鱼钩 9507200000、钓线轮 9507300000、拟饵 9507900000；接口 `GET /api/master-data/hs-presets?category=fishing` 可查，只做参考，确认后再录入 HS 模板。**钓鱼线没有预设**：归类要看是否零售包装和规格。中国：零售包装的钓鱼线成品是 9507900000。美国：HTS 9507.90.20.00「Fishing line put up and packaged for retail sale」。CBP HQ 954309（1994）和 HQ 956007（1994，撤销 NY 884900）认定：切成长度、绕在线轴上、装进盒子或吸塑零售包装并明确标为钓鱼线的尼龙单丝，归 9507.90.20；只绕在线轴上、没有零售包装和鱼线标识的，不算“制成钓鱼线”，按材质归 5404（合成单丝 ≤1mm）、3916（>1mm 塑料单丝）或 5607（编织线）。较早的 NY 882320（1993）曾把成卷鱼线归 5404 / 3916 / 5607，后来 HQ 954309 明确了上面的标准。请按实物确认（必要时问报关行）后再录入。
- **其他提示**：标签尺寸只接受 10–600 mm；不是 PDF 或已损坏的 PDF 会说明是哪个文件；同一货件 CSV 传了两份会直接报错；产品库批量修改表里同一 SKU 出现多行时这几行都不写入；领星新品里 SKU 像乱码或缺 FNSKU/ASIN 的会单独列为“需复核”，默认不勾；产品库按 SKU 修改字段时 SKU 不存在会提示。
