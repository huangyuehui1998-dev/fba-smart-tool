### 3.2 反推出的规则

1. **分组**：一个 FBA 货件（一票）对应一份发票。文件命名：A 是 `J-US-第N批第M票美国海运{仓库}-{箱数}箱-{英文品名}发票.xlsx`，C 是 `{FBA货件号}发票.xlsx`。
2. **明细粒度**：
   - B 和 C：**同一 SKU、同一箱规的连续箱号合并成一行**（`1-13`、`14-21`；B 用 `U000001-5`）。
   - D：Invoice 按 SKU 汇总，Packing list 一箱一行。
   - A：一票一行，多个 SKU 用逗号隔开。
3. **申报单价**：样例里都是**亚马逊售价（USD）**。比如 SEND 模板里申报单价 = 链接售价 = 39.99 / 49.99，九方 Invoice 也是 39.99 / 49.99；第 3 批 A 模板的单个货值是 42.99，和报关单单价 42.99 一样。采购单价 CNY（50 / 70）只是附带填写。
   - 琪珞模板里同一种产品出现了 38.99 / 28.99 / 35.99 三个价，可能是不同尺寸的 SKU 各自的售价（琪珞已定为不投入，不再追查）。
   - ~~v6 已定（Q4 选 B）：以后申报单价优先取产品库手填的 `declared_value`，没填时用售价并警告。~~ **【改 s2-fix2】按实时售价报：领星 `listing_price` 第一，手填 `declared_value` 第二**，其后领星 price/landed_price、旧值（警告）；手填价未采用时提示；无价格阻断（依据 /workspace/用户决策记录.md D-2026-10-16-01：06:04 对话原话 + 06:27 书面确认“是，领星价优先、MCP 为主”，美东）。
4. **数量单位**：宠物垫是“包”，车载狗栏是“个”，第 6 批宠物围栏是“箱”。单位跟着产品走，应该放进产品库。
5. **单箱毛重**：
   - SEND 模板按 SKU 填固定值（7.5 / 9.5）。
   - 九方 Packing list 用的是**仓库实测**的逐箱数据（6.94–9.92）。
   - 两者合计不一样（173.5 vs 169.89）。
6. **总额**：九方 Invoice 是 Σ(数量×单价)，没有凑整（1599.68 + 2079.48 = 3679.16）。
7. **地址**：收件人信息由仓库代码查 FBA 仓库地址库得到（B 模板的 `！` 表，D 模板的派送地址）。
8. **图片**：A/B/C/D 都要求带产品图片。A 模板因为嵌入了图，单个文件到 9–11MB。

### 4.6 v5 决定与历史样例的对照（只读核对）

**九方 Packing list 单箱毛重合计**（脚本逐份读取 Packing list，再和对应报关单比较）：

| 九方文件 | 箱数 | Packing list 单箱毛重合计 | 对应报关单 F12 毛重 / G12 净重 | 关系 |
|---|---|---|---|---|
| LCL2609TNKDA（JUS14DD12） | 12 | 112.8 | 115.2 / 112.8 | 合计 = **净重**，毛重 = 合计 + 0.2×12 |
| LCL2610DHTZA（JUS15DD6） | 6 | 120.0 | 121.2 / 120.0 | 合计 = **净重**，毛重 = 合计 + 0.2×6 |
| LCL2610S97BA（JUS15DD5SBD） | 5 | 100.0 | 101 / 100 | 同上 |
| LCL2609PU1DA（JUS13DD21） | 21 | 169.89 | 173.5 / 164.825 | 都对不上；报关毛重来自 SEND 发票（13×7.5 + 8×9.5 = 173.5） |

**结论**：
- 第 13 批（SEND 发票）：发票单箱重合计 = 报关**毛重**，和用户的 Q2 一致。
- 第 14、15 批（九方 Packing list）：单箱重合计 = 报关**净重**，毛重是倒推加回去的（+0.2kg/箱），和“毛重 = 发票合计、净重 = 毛重 − 0.2”的方向相反。
- 按 v5 规则重算，JUS14DD12 会得到毛重 112.8、净重 110.4，样例是 115.2 / 112.8。**v6 已定（B1 选 A）**：九方也按新规则算，这个差异写进黄金样例的 `expected_diff`。九方单箱重是否含箱子待外部核实（§7.1 E2）。

**舍入**：
- 样例里的发票单箱重都是 1–2 位小数：九方 8 份最多 2 位，SEND 是 7.5 / 9.5。
- 用 Decimal 计算时，“2 位小数的合计 − 0.2×箱数”结果仍是 2 位以内，**不需要舍入，Q1 的舍入和小数位不需要用户确认**。
- 系统规则：单箱重最多 2 位小数，超过 2 位时录入校验报错，不做静默舍入。
- 计算全部用 Decimal，避免浮点误差。
