## 代码方

看的是文档是否和当前源码一致，以及钥匙有没有重新进树。

核对过：

- `APP_VERSION` 仍是 `V4`（`backend/fba_tool/app_version.py`）。
- 便携包工作流 `.github/workflows/portable-windows.yml` 的名字是 Portable Windows package，tag 过滤 `v4*`，只上传 artifact。
- `forbidden_real_hits` 不再有 `ALLOWED_LISTING_FIXTURES`。`review/lingxing_listing_export_2026-10-21.xlsx` 不在当前树。
- `LICENSE` 是 MIT，版权 2026 huangyuehui1998-dev。
- 跟踪文本里的 `sk-` / `dpapi:v1:` 仍是前缀、脱敏测试串和旧评审笔记。`frontend/.env.example` 仍是注释和占位。

要改的地方：

1. README 把流程写成自拟的 1 到 7，和 `frontend/src/lib/workflow-steps.ts` 不符。界面是「1 录入、2 排箱、3 导出、4 货件校验、5 发票、6 报关、7 刷仓」。step id 分别是 1、2、3、4、4.5、5、3.5。「5 发票」的 id 是 4.5，「7 刷仓」的 id 是 3.5。
2. DeepSeek Key 不是泛泛的「本机设置」。`backend/fba_tool/deepseek_secret.py` 只在 Windows 用 DPAPI 写到 `app_data/secrets/deepseek_key.bin`。非 Windows 的 `PUT /api/settings/deepseek-key` 返回 422。领星钥匙仍是 `app_data/config/lingxing.json` 里的 `mcp_key_enc`。
3. 日常入口 `run_app.py` 绑定 `127.0.0.1`，首选端口 8002，并跳过 8010。`python backend/main.py` 在没设 `FBA_PORT` 时用 8000。`FBA_HOST` 不是回环地址时，必须有 `FBA_ACCESS_TOKEN`，否则 `backend/security.py` 拒绝启动。
4. `CHANGELOG.md` 里的 `[4.x] - 未发布` 和 `Unreleased` 叠在一起，不像 Keep a Changelog。未发布的说明留在 `Unreleased` 即可。

结论：开源边界和源码一致。上面四处是文档误差，本提交已改。没有新的明文钥匙。

## 测试方

看的是贡献文档里的命令能不能照着跑，以及「没有真实表也能测」这句话是否成立。

`fde3f39` 上已经跑过：

`tests/release/test_s9step5_release.py::test_manifest_excludes_real_data_files`、`test_masterdata_rules.py::test_listing_xlsx_round_trip_and_forbidden_names`、`tests/v4/test_v4_phase_ab.py`、`tests/v4/test_v4_ops_r3.py`。

结果 **54 passed，2 skipped**（26.46s）。跳过是「未设置 `FBA_LINGXING_OWNER_XLSX`」和「需要 box realdata」。`forbidden_real_hits` 为空。本提交不改测试代码。订正文档后再跑同一组：**54 passed，2 skipped**（23.43s），跳过原因不变。

要改的地方：

1. README 写「没有这些文件，CI 仍然应该是绿的」。仓库里的 GitHub Actions 目前只有便携包，不跑 pytest。绿不绿和这两组 skip 不是一回事。
2. `scripts/smoke_e2e.py` 的用法写明在仓库根目录。CONTRIBUTING 原先把这条命令放在后端、前端命令后面，工作目录不清楚。
3. `FBA_REALDATA_DIR` 没设时，并不是所有用例都直接 skip。`backend/tests/smoke/reference.py` 会退回 `/workspace/fba_tool/realdata`。路径不存在才 skip，原因里带「需要 box realdata」。`FBA_LINGXING_OWNER_XLSX` 才是「没设或文件不存在就 skip」，没有仓库内默认路径。
4. Vite 代理端口先读 `.dev/ports.json` 的 `backend`，其次 `FBA_BACKEND_PORT`，否则 8002（`frontend/vite.config.ts`）。

结论：合成夹具和 owner 文件的 skip 是成立的。文档把 CI、冒烟目录和 realdata 默认路径说严了。
