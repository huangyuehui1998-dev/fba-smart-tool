## 二、新缺陷

以下全部是轻微问题，没有严重或中等问题。

1. **N2-b Excel 提示措辞矛盾（−0.2，建议修）**
   - 位置：`backend/fba_tool/product_import.py:96` 生成「第N行价格“原值”无效：原因，这一行已跳过」；`product_import.py:183` 的 apply 只要有一行无效就抛 ImportRowsError；`routers/master_data.py:252-257` 返回 422。
   - 实测：导入预览 200，列出坏行，说「这一行已跳过」；点确认写入后，整份文件 422，**同一文件里的合法行也没写**，422 的 message 里仍然写着「这一行已跳过」。
   - 422 带行号和原值，本身符合上轮的修复要求，问题在措辞：用户会以为坏行跳过、其余行已写入。
   - 建议二选一：确认写入时只跳过坏行，其余行照写，与定时同步一致；或者把措辞改成「请先修正第N行，修正前整个文件不会写入」。
2. **N3-b 舍入方式不一致（−0.1）**
   - 位置：`lingxing_adapter.py:80` 的 `d.quantize(Decimal("0.01"))` 没指定 rounding，所以用默认的 ROUND_HALF_EVEN。
   - 实测："12.345"→12.34，"12.005"→12.00，"0.005"→判为无效；而 `customs_package.py`、`invoice_rules.py` 等处用 ROUND_HALF_UP。
   - 建议统一用 ROUND_HALF_UP，并补一条边界测试。
3. **重复提示（−0.1）**
   - 位置：`lingxing_adapter.py:128-135`。同一行数据在多个售价别名键里放了同一个坏值时，每个键各记一条 issue，消息里不带键名，所以文字完全一样。
   - 影响：预览里同一条「领星售价“12,5”无效…」显示 3 次（见截图 wide_1280，DEMO-BADPRICE）；定时同步差异 `price_invalid` 里同一 SKU 也出现 3 条一样的。
   - 建议按 (field, raw, reason) 去重。
4. **N5/N6-b 三条通道判定不完全一致；限流词太宽（−0.1）**
   - 位置：`lingxing_mcp_client.py:85`（_RATE_LIMIT_WORDS）、`:101-107`（_is_auth_code）、`:122`（信封）、`:188`（JSON-RPC）、`:475`（HTTP）。
   - 实测一：403 的文字以「MCP Key无效或已失效」开头、同时带限流词时，信封和 HTTP 通道重试 3 次，JSON-RPC 通道因为前缀优先，直接判鉴权失败。
   - 实测二：限流词「频繁」会命中「账号因频繁违规已被禁用」这类封禁文字，导致重试 3 次。
   - 建议：鉴权前缀在三条通道都优先；把「频繁」收窄成「请求过于频繁 / 调用频繁」。
5. **UI (h)（−0.1）**
   - 位置：`lingxing-preview-panel.tsx:91` 把内部规则编号「（D-12）」直接给用户看；`:90` 和 `lingxing_preview.py:307` 一起显示时，成了「（来源：正常价（领星常规价））」，括号套括号。
   - 建议去掉 D-12，来源改成「来源：正常价 · 领星常规价」。
6. **UI (i)（−0.1）**
   - 场景：售价 12、领星常规价 12.5（DEMO-SMALL）。
   - 实测：申报 USD 12.00（来源：售价），不算促销，没有琥珀色，**申报值正确**。
   - 问题：价格行只列出「领星常规价 USD 12.50（本次领星）」，没有说明为什么不用它。面板顶部的用词说明写着「领星常规价高于售价时用它」作正常价，用户容易误以为该按 12.5 申报。
   - 建议加一句「（高于售价不到 5%，不算促销，按售价申报）」。
7. **UI (j)（−0.1）**
   - 位置：`lingxing_preview.py:287-302`。
   - 问题：「低>5%」读起来别扭；同一面板里同时出现「低25.0%」「低5.40%」「低>5%」三种精度，而且「低」和数字之间没有空格。
   - 建议写成「低 5% 以上」，或统一一位小数，>5% 但向下取整后为 5.0 时写「低 5.0% 以上」。
8. **UI (k)（−0.1）**
   - 位置：`lingxing-preview-panel.tsx:50-52`（Seg 用 whitespace-nowrap）、`:72-76`（促销片段是一整段不换行，约 35 个字）。
   - 实测：420px 宽时整个面板横向溢出，右侧被裁掉，包括「8/8 字段（点击展开勾选）」、琥珀色行的尾部和顶部说明；600px、900px 正常。桌面版很少这么窄，所以记为轻微。
   - 建议：促销片段内部再拆成几段，或给面板加 min-w-0 / break-words。
