## 二、观察项

**O1【低，扣 1 分】按文件名识别仓库可能误识别**
- 位置：`shipment_parser.py` 中的 `_warehouse_from_filename`，用的正则是 `[A-Z]{3}[0-9][A-Z0-9]?`。
- 复现：“JAN5批次.csv”识别成 `JAN5`，“USA1.csv”识别成 `USA1`。
- 影响有限：只有货件名称里没有仓库代码时才会按文件名识别。
- 建议：
  1. 和已知仓库表对比，或者在页面上标明“来自文件名”，让用户确认；
  2. 补一条反例测试。

**O2【低，不扣分】有几处调用没有传文件名**
- 位置：`shipment_serialize.py` L72、`fba_parser.py` L19、`product_catalog.py` L245、`services/shipment_service.py` L192。
- 这几处调用 `parse_csv_shipment` 时不带 `file_name`，遇到“待分配”的票时仓库会是 `UNKN`。这是安全的降级，不会识别错，但信息不完整。
- 主流程 `routing.py` 和 `shipment_validator.py` 已经传了文件名。

**O3【低，不扣分】GET `?token=` 仍会把口令写进访问日志**
- 已经有 POST 方式，文档也写了提醒。
- 建议后续在日志里屏蔽 query 参数，或者在 GET 带 token 时提示改用 POST（方案 3.7）。

**O4【提示】Excel 箱规留空的行，在结果表里先以 0 占位**
- 这些行会带提示，并由产品库补齐；产品库里也没有时，由 Step1 校验拦下。
- 本轮没有做端到端验证（需要产品库数据，我没有读 app_data），所以只记录，不扣分。
