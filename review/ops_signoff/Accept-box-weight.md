## 2. 继承口径摘要（不重开产品争论）

摘自 OPS2-O4 / OPS3-O4 / 统一稿既有定论（本壳只挂载，不改口径）：

1. **超 FBA/内部预警限重**（排箱侧常见 ~**22.5 kg** 内部预警 / ~50 lb 标准件线）→ **warn**（可继续；文案须标明「内部余量 / 预警」来源）。  
2. **超库硬限**（箱规库毛重等字段约 **70 kg**）→ **阻断**（保存/导入 **400/422** 或等价拒绝），并注明阈值来源。  
3. **固定两例 checklist**：一条 **>预警且 <70** → 见 warn；一条 **>70** → 见阻断。  
4. **文案来源**须核对 UI 与 API 一致（向导提示 vs 保存/导入拒绝）。  
5. **`使用说明`** 排箱/箱规节至少 **一句** 说明 warn vs 硬限。  
6. 若代码已证明 UI/API 一致，**可仅文档 + 本 checklist 签字**结项（OPS3-O4）；仍须本 Accept 条件表全绿。  
7. 仓库用**合成边界**；真实过机/STA 表不入库。
